
## Память 

Посмотреть используемую память

```bash
df -h # общий отчет

sudo du -h --max-depth=1 / 2>/dev/null | sort -h # по папкам
```

### Память докера

```bash
docker system df # Общая инфа о занимаемой памяти

docker builder prune # Почистить кэш builder'а

docker image prune # Удалить неиспользуемые образы
```

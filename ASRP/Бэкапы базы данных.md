
## Что бэкапить

Лучше всего делать бэкапы сразу всей базы данных, чтобы можно было восстановить базу целиком

```bash
pg_dump -U "$DB_USER" -d "$DB_NAME" -Fc -Z 6 --no-owner --no-acl > backup.dump
```


- `Fc` - `--format=custon` - кастомный формат, а не обычный SQL-файл. Удобен тем, что можно восстанавливать через pg_restore
- `-Z 6` - уровень сжатия дампа
- `--no-owner` - не сохраняет команды, которые пытаются восстановить владельцев пользователей
- `--no-acl` - не сохраняет права доступа

### Восстановление через `pg_restore`

```bash
pg_restore -U "$DB_USER" -d "$DB_NAME" --no-owner --no-acl backup.dump
```


## Формат cron

Строка выглядит так

```bash
* * * * * command
│ │ │ │ │
│ │ │ │ └── день недели: 0-7, где 0 и 7 = воскресенье
│ │ │ └──── месяц: 1-12
│ │ └────── день месяца: 1-31
│ └──────── час: 0-23
└────────── минута: 0-59
```

### Пример

Каждый день в 03:00

```bash
0 3 * * * /path/to/script.sh
```

Каждые 15 минут

```bash
*/15*
```


Добавить новую задачу

```bash
crontab -e # открыть редактор

crontab -l # проверить, что задача добавлена
```

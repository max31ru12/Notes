
## Сохранить модель

```python
from sentence_transformers import SentenceTransformer  
  
  
model = SentenceTransformer(  
    "sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2"  
)  
  
# Сохранить модель на флешку  
model.save(  
    r"E:\models\my_embedding_model"  
)
```


## На другом компьютере

Копируешь, например:

```
E:\models\my_embedding_model
```

в:

```
D:\AI\models\my_embedding_model
```

И вместо названия модели:

```
SentenceTransformer(
    "sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2"
)
```

передаёшь путь:

```
from sentence_transformers import SentenceTransformer


model = SentenceTransformer(
    r"D:\AI\models\my_embedding_model",
    local_files_only=True,
)
```

Интернет **не нужен**.
